# 4H REGIME 추천 Event-Action Table 초안

## 1. 문서 범위

- 대상 상태 머신: `4H_REGIME_Recommendation.png`
- 목적: 4시간봉 기준 REGIME 추천 상태와 전이 조건을 Event-Action 형식으로 정리한다.
- 보조 대조 자료: 같은 경로의 `regime_design.md`
- 범위 제한: 이 상태 머신의 액션은 **TYPE 0~4 추천값 산출**까지이다. 사용자의 실제 REGIME 선택이나 30분봉 매매 로직 실행은 이 표의 범위에 포함하지 않는다.
- 상태 머신 이미지에 없는 이벤트명은 초안임을 알 수 있도록 `가정`으로 표시했다.

## 2. 상태 및 입력 정의

### 2.1 상태

| 상태 | 의미 |
|---|---|
| `Initial` | 검은 원으로 표시된 시작 의사 상태 |
| `4H Candle Evaluation` | 4시간봉 기반 추천 조건을 평가하는 상태 |
| `Type_0 추천 (횡보)` | 횡보 REGIME 추천 상태 |
| `Type_1 추천 (약상승)` | 약상승 REGIME 추천 상태 |
| `Type_2 추천 (강상승)` | 강상승 REGIME 추천 상태 |
| `Type_3 추천 (약하락)` | 약하락 REGIME 추천 상태 |
| `Type_4 추천 (강하락)` | 강하락 REGIME 추천 상태 |

### 2.2 조건식 기호

| 기호 | 초안 해석 |
|---|---|
| `ema9_slope` | 4H EMA9 기울기. 보조 문서 기준 단위는 `% / 4H봉`이다. |
| `HH` | 최근 스윙 고점이 이전 스윙 고점보다 유의하게 높은 상태(Higher High) |
| `HL` | 최근 스윙 저점이 이전 스윙 저점보다 유의하게 높은 상태(Higher Low) |
| `LH` | 최근 스윙 고점이 이전 스윙 고점보다 유의하게 낮은 상태(Lower High) |
| `LL` | 최근 스윙 저점이 이전 스윙 저점보다 유의하게 낮은 상태(Lower Low) |
| `HH + HL` | 이미지의 원문 표기. 보조 문서에 따라 `HH`와 `HL`이 모두 성립하는 강상승 구조로 해석한다. |
| `LH + LL` | 이미지의 원문 표기. 보조 문서에 따라 `LH`와 `LL`이 모두 성립하는 강하락 구조로 해석한다. |
| `current_price` | 평가 시점의 현재가 |
| `realtime_4h_ema9` | 평가 시점의 실시간 4H EMA9 값 |

| EA-006 | `4H Candle Evaluation` | 평가 수행 (`가정`) | `-0.30 < ema9_slope < -0.15` | 추천값을 `TYPE_3`으로 설정한다. | `Type_3 추천 (약하락)` | 기울기만으로 약하락을 추천하는 구간이다. |
| EA-007 | `4H Candle Evaluation` | 평가 수행 (`가정`) | `(ema9_slope <= -0.30) && ((LH + LL) && !(current_price <= realtime_4h_ema9))` | 추천값을 `TYPE_3`으로 설정한다. | `Type_3 추천 (약하락)` | 이미지 원문 그대로이다. 강하락 구조는 성립하지만 현재가가 EMA9 이하 조건을 충족하지 않은 경우이다. 구조 자체가 미충족인 경우는 이 조건에 포함되지 않는다. |
| EA-008 | `4H Candle Evaluation` | 평가 수행 (`가정`) | `(ema9_slope <= -0.30) && ((LH + LL) && (current_price <= realtime_4h_ema9))` | 추천값을 `TYPE_4`로 설정한다. | `Type_4 추천 (강하락)` | 강하락 기울기, `LH + LL`, 현재가의 EMA9 이하 조건을 모두 요구한다. |

## 4. 판정 구간 및 경계값 검토

| `ema9_slope` 범위 | 추가 조건 | 추천 결과(이미지 기준) |
|---|---|---|
| `ema9_slope <= -0.30` | `LH + LL` 성립, `current_price <= realtime_4h_ema9` | `TYPE_4 강하락` |
| `ema9_slope <= -0.30` | `LH + LL` 성립, `current_price > realtime_4h_ema9` | `TYPE_3 약하락` |
| `ema9_slope <= -0.30` | `LH + LL` 미성립 | **정의되지 않음 — 확인 필요** |
| `-0.30 < ema9_slope < -0.15` | 없음 | `TYPE_3 약하락` |
| `-0.15 <= ema9_slope <= 0.15` | 없음 | `TYPE_0 횡보` |
| `0.15 < ema9_slope < 0.30` | 없음 | `TYPE_1 약상승` |
| `ema9_slope >= 0.30` | `HH + HL` 성립, `current_price >= realtime_4h_ema9` | `TYPE_2 강상승` |
| `ema9_slope >= 0.30` | 위 강상승 복합 조건이 성립하지 않음 | `TYPE_1 약상승` |

경계값은 `-0.30`이 강하락 분기, `-0.15`와 `0.15`가 횡보 분기, `0.30`이 강상승 복합 판정 분기에 포함된다.

## 5. 확인 필요 사항

1. **강하락 실패 분기의 조건 공백**  
   이미지의 `TYPE_3` 강하락 실패 분기는 다음과 같다.

   ```text
   (ema9_slope <= -0.30)
   && ((LH + LL) && !(current_price <= realtime_4h_ema9))
   ```

   이 조건은 `ema9_slope <= -0.30`이면서 `LH + LL` 구조가 성립하지 않는 경우를 처리하지 않는다. 반면 `regime_design.md`의 결정 트리는 강하락 복합 조건이 성립하지 않으면 모두 `TYPE_3`을 추천한다. 설계 의도가 보조 문서와 같다면 이미지 조건은 아래처럼 복합 조건 전체를 부정해야 한다.

   ```text
   (ema9_slope <= -0.30)
   && !((LH + LL) && (current_price <= realtime_4h_ema9))
   ```

2. **변수명 불일치**  
   횡보 분기만 `ema_9_slope`, 나머지 분기는 `ema9_slope`로 표기되어 있다. 동일 변수인지 확인하고 구현 명칭을 하나로 통일해야 한다.

3. **`HH + HL`, `LH + LL` 연산자 의미**  
   본 초안은 보조 문서에 따라 각각 두 구조 조건이 모두 참이라는 뜻으로 해석했다. 구현에서는 산술 덧셈이 아니라 명시적인 논리곱(`HH && HL`, `LH && LL`) 또는 별도 구조 판정값을 사용할지 확정해야 한다.

4. **초기 평가 이벤트와 데이터 준비 조건**  
   시작 의사 상태에서 `4H Candle Evaluation`으로 가는 화살표에는 라벨이 없다. 애플리케이션 시작, 종목 선택, 캔들 데이터 로딩 완료 중 어느 이벤트가 최초 평가를 발생시키는지 정해야 한다. EMA9와 스윙 구조를 계산할 최소 데이터가 없을 때의 처리도 필요하다.

5. **평가 시점의 입력 스냅샷**  
   재평가는 4H봉 마감 시점으로 보이지만 `current_price`와 `realtime_4h_ema9`를 정확히 어느 시각의 값으로 고정하는지 이미지에는 정의되어 있지 않다. 동일 평가 안에서는 하나의 일관된 입력 스냅샷을 사용하는 것이 필요하다.

6. **결측치 및 계산 실패 처리**  
   `ema9_slope`, 스윙 구조, 현재가, 실시간 EMA9가 결측 또는 비정상 값일 때 유지·재시도·기본 추천 중 어떤 액션을 수행할지 정의되어 있지 않다.

7. **추천 상태 갱신의 부수 효과**  
   추천값 저장, GUI 표시, 로그/알림 발행 여부와 동일 TYPE 재추천 시 중복 이벤트를 발행할지 여부는 별도 확정이 필요하다.

## 6. 구현용 정규화 초안

아래는 이미지와 보조 문서의 의도를 하나의 완전한 결정 트리로 정규화한 참고 초안이다. **EA-007의 이미지 원문과 다른 부분이 있으므로 확인 후 채택해야 한다.**

```text
if ema9_slope >= 0.30:
    if HH_and_HL and current_price >= realtime_4h_ema9:
        recommend TYPE_2
    else:
        recommend TYPE_1
elif 0.15 < ema9_slope < 0.30:
    recommend TYPE_1
elif -0.15 <= ema9_slope <= 0.15:
    recommend TYPE_0
elif -0.30 < ema9_slope < -0.15:
    recommend TYPE_3
elif ema9_slope <= -0.30:
    if LH_and_LL and current_price <= realtime_4h_ema9:
        recommend TYPE_4
    else:
        recommend TYPE_3
```
