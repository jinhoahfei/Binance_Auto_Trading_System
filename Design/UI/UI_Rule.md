# UI Rule 명세서

## 1. 문서 목적

본 문서는 Basic Iterative 자동매매 UI 프로토타입을 기준으로, 화면 객체가 따라야 하는 UI 규칙을 정의한다. 이 문서는 UI 객체의 동작 규칙을 다음 세 가지 관점으로 분리하여 정의한다.

1. **Constant Behaviour**: 현재 상태와 무관하게 항상 같은 방식으로 동작하는 UI 객체의 규칙
2. **Varying Behaviour**: 자동매매 실행 여부, 보유 포지션 여부, 날짜 선택 상태, 저장 위치 선택 여부 등에 따라 다르게 동작하는 UI 객체의 규칙
3. **Entry & Exit Rule**: 화면 또는 팝업에 진입할 때 수행되는 규칙과, 화면 또는 팝업을 벗어날 때 수행되는 규칙

본 문서에서 말하는 “화면”은 전체 페이지 단위의 UI를 의미하고, “팝업”은 현재 화면 위에 표시되는 모달 또는 플로팅 패널을 의미한다.

## 3. UI Rule 작성 기준

각 규칙은 다음 정보를 기준으로 정의한다.

| 항목 | 의미 |
|---|---|
| Rule ID | 규칙 식별자이다. Constant Behaviour는 `CR`, Varying Behaviour는 `VR`, Entry & Exit Rule은 `ER` 접두사를 사용한다. |
| 대상 UI 객체 | 규칙이 적용되는 버튼, 탭, 슬라이더, 팝업, 화면 영역이다. |
| 사용자 이벤트 | 사용자가 발생시키는 클릭, 선택, 드래그, 화면 진입, 화면 이탈 이벤트이다. |
| 선행 조건 | 해당 규칙이 적용되기 위해 필요한 현재 상태이다. Constant Behaviour에서는 보통 `항상`으로 작성한다. |
| 시스템 반응 | 이벤트 발생 후 UI가 수행해야 하는 Action이다. |
| 상태 변경 | 선택값, 자동매매 상태, 날짜 범위, 필터 상태, 팝업 표시 상태 등 내부 상태의 변경이다. |
| 시각적 피드백 | 버튼 강조, 토글 ON/OFF, 팝업 표시, 테이블 갱신 등 사용자가 확인할 수 있는 변화이다. |

---

# 4. Constant Behaviour

Constant Behaviour는 현재 자동매매 상태, 보유 포지션 여부, 날짜 범위, 저장 위치 선택 여부와 무관하게 항상 같은 방식으로 반응하는 UI 규칙이다.

---

## CR-01. 상단 상태 표시 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `STR-AUTO`, `Basic Iterative`, `LIVE` 상태 표시 영역 |
| 사용자 이벤트 | 없음 |
| 선행 조건 | 메인 화면 또는 거래 내역 상세 화면이 표시된 상태 |
| 시스템 반응 | 현재 실행 중인 전략 이름과 실시간 연결 상태를 표시한다. |
| 상태 변경 | 없음 |
| 시각적 피드백 | 실시간 연결이 정상인 경우 `LIVE`가 초록색 상태로 표시된다. |

`LIVE`는 버튼이 아니라 상태 표시 객체이다. 사용자가 클릭해도 별도의 화면 이동이나 팝업 표시를 수행하지 않는다.

---

## CR-02. 단일 선택 그룹 공통 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | REGIME type 버튼, 차트 주기 버튼, 트레이더 패널 탭, 거래 내역 필터 버튼, CSV 기간 프리셋 버튼 |
| 사용자 이벤트 | 단일 선택 그룹 내 버튼 클릭 |
| 선행 조건 | 같은 그룹 안에 여러 선택지가 존재하는 상태 |
| 시스템 반응 | 클릭된 항목만 선택 상태로 만들고, 같은 그룹의 나머지 항목은 비선택 상태로 변경한다. |
| 상태 변경 | 해당 그룹의 현재 선택값이 클릭된 항목으로 변경된다. |
| 시각적 피드백 | 선택된 버튼은 강조 색상으로 표시되고, 비선택 버튼은 일반 상태로 표시된다. |

단일 선택 그룹은 동시에 두 개 이상의 항목이 활성화될 수 없다. 예를 들어 차트 주기에서 `1분`과 `30분`이 동시에 선택되어서는 안 된다.

---

## CR-03. REGIME type 버튼 선택 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `type0 횡보`, `type1 약상승`, `type2 강상승`, `type3 약하락`, `type4 강하락` 버튼 |
| 사용자 이벤트 | REGIME type 버튼 클릭 |
| 선행 조건 | 메인 화면이 표시된 상태 |
| 시스템 반응 | 클릭된 REGIME type으로 실행할 것인지 확인하는 REGIME type 선택 확인 팝업을 표시한다. |
| 상태 변경 | REGIME type 선택 확인 팝업 표시 상태가 `open`으로 변경되고, 확인 대상 REGIME type이 클릭된 type으로 저장된다. |
| 시각적 피드백 | 배경 메인 화면은 어둡게 처리되고, `REGIME type을 실행할까요?` 확인 팝업이 중앙에 표시된다. |

REGIME type 버튼은 클릭 즉시 최종 적용되지 않는다. 사용자가 type 버튼을 클릭하면 선택 확인 팝업을 먼저 표시하고, 해당 팝업에서 `실행`을 눌렀을 때 선택된 REGIME type을 실제 적용한다.

## CR-04. 차트 주기 버튼 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `1분`, `30분`, `4시간`, `1일` 버튼 |
| 사용자 이벤트 | 차트 주기 버튼 클릭 |
| 선행 조건 | ETH 가격 차트가 표시된 상태 |
| 시스템 반응 | ETH 가격 차트의 캔들 주기를 클릭된 주기로 변경한다. |
| 상태 변경 | 현재 차트 주기 상태가 클릭된 주기로 변경된다. |
| 시각적 피드백 | 선택된 주기 버튼이 강조 표시되고 차트가 해당 주기의 캔들 데이터로 다시 렌더링된다. |

차트 주기 변경은 REGIME 선택값, 자동매매 실행 상태, 분할 매수 비율, 분할 매도 비율을 초기화하지 않는다.

## CR-05. 지표 설정 버튼 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `지표 설정` 버튼 |
| 사용자 이벤트 | `지표 설정` 클릭 |
| 선행 조건 | ETH 가격 차트가 표시된 상태 |
| 시스템 반응 | 차트 위에 지표 설정 팝업을 표시한다. |
| 상태 변경 | 지표 설정 팝업 표시 상태가 `open`으로 변경된다. |
| 시각적 피드백 | `차트 설정` 팝업이 차트 영역 위에 표시된다. |

지표 설정 팝업은 메인 화면을 벗어나지 않고 현재 차트 위에 표시된다. 팝업이 표시되어도 메인 화면의 차트, 트레이더 패널, 거래/계좌 영역의 데이터 상태는 유지된다.

## CR-06. 차트 보조지표 토글 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `EMA9`, `볼린저밴드`, `거래량(Volume)` 토글 |
| 사용자 이벤트 | 각 토글 클릭 |
| 선행 조건 | 지표 설정 팝업이 표시된 상태 |
| 시스템 반응 | 클릭된 보조지표의 표시 여부를 ON/OFF로 전환한다. |
| 상태 변경 | 해당 보조지표의 표시 상태가 변경된다. |
| 시각적 피드백 | 토글의 ON/OFF 상태가 변경되고, 차트에 해당 지표가 표시되거나 제거된다. |

각 보조지표 토글은 서로 독립적으로 동작한다. `EMA9`를 OFF하더라도 `볼린저밴드`와 `거래량(Volume)`의 표시 상태는 변경되지 않는다.

## CR-07. 트레이더 패널 탭 전환 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `체결 내역` 탭, `실시간 지표` 탭 |
| 사용자 이벤트 | 탭 클릭 |
| 선행 조건 | 메인 화면의 트레이더 패널이 표시된 상태 |
| 시스템 반응 | 우측 트레이더 패널의 표시 내용을 선택된 탭에 맞게 교체한다. |
| 상태 변경 | 현재 트레이더 패널 탭 상태가 클릭된 탭으로 변경된다. |
| 시각적 피드백 | 선택된 탭이 강조 표시되고, 패널 내부 콘텐츠가 교체된다. |

`체결 내역` 탭을 선택하면 최근 체결 목록이 표시되고, `실시간 지표` 탭을 선택하면 실시간 지표 목록이 표시된다. 탭 전환은 메인 차트와 거래/계좌 영역을 초기화하지 않는다.

## CR-08. 전체 보기 버튼 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | 트레이더 패널의 `전체 보기` 버튼 |
| 사용자 이벤트 | `전체 보기` 클릭 |
| 선행 조건 | 메인 화면의 `체결 내역` 탭이 표시된 상태 |

| 상태 변경 | 현재 화면 상태가 `Main Screen`에서 `Trade History Detail Screen`으로 변경된다. |
| 시각적 피드백 | 메인 화면 대신 거래 내역 상세 화면이 표시된다. |

거래 내역 상세 화면으로 이동할 때 자동매매 실행 상태, REGIME 선택값, 차트 주기, 분할 매수/매도 설정값은 유지되어야 한다.

## CR-09. 분할 매수/매도 조정 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | 분할 매수 `-`, 분할 매수 슬라이더, 분할 매수 `+`, 분할 매도 `-`, 분할 매도 슬라이더, 분할 매도 `+` |
| 사용자 이벤트 | `-` 클릭, `+` 클릭, 슬라이더 드래그 |
| 선행 조건 | 메인 화면의 거래/계좌 영역이 표시된 상태 |
| 시스템 반응 | 분할 매수 또는 분할 매도 비율을 변경한다. |
| 상태 변경 | 해당 주문 비율 설정값이 변경된다. |
| 시각적 피드백 | 슬라이더 위치와 현재 비율 배지가 변경된다. |

분할 매수/매도 비율 변경은 이미 제출된 주문에는 영향을 주지 않고, 이후 생성되는 신규 주문부터 적용된다.

## CR-10. 거래 내역 상세 필터 버튼 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | `오늘`, `전체`, `매수`, `매도` 버튼 |
| 사용자 이벤트 | 필터 버튼 클릭 |
| 선행 조건 | 거래 내역 상세 화면이 표시된 상태 |

## CR-11. CSV 내보내기 버튼 규칙

| 항목 | 내용 |
|---|---|
| 대상 UI 객체 | 거래 내역 상세 화면의 `CSV 내보내기` 버튼 |
| 사용자 이벤트 | `CSV 내보내기` 클릭 |
| 선행 조건 | 거래 내역 상세 화면이 표시된 상태 |
| 시스템 반응 | CSV 내보내기 팝업을 표시한다. |
| 상태 변경 | CSV 내보내기 팝업 표시 상태가 `open`으로 변경된다. |
| 시각적 피드백 | 거래 내역 상세 화면 위에 `CSV 내보내기` 팝업이 표시된다. |

CSV 내보내기 팝업이 표시되더라도 배경의 거래 내역 상세 화면은 유지된다. 단, 팝업이 열린 상태에서는 배경 화면의 테이블 조작보다 팝업 조작이 우선된다.

| 항목 | 내용 |

| 사용자 이벤트 | `위치 선택` 클릭 |

# 5. Varying Behaviour

Varying Behaviour는 같은 UI 객체라도 현재 시스템 상태나 입력값에 따라 다른 결과를 내는 규칙이다. 이 영역에서는 반드시 조건과 분기 결과를 함께 정의한다.

---

## VR-01. 자동매매 실행 버튼 상태 분기 규칙

| 현재 상태 | 사용자 이벤트 | 시스템 반응 | 상태 변경 | 시각적 피드백 |
|---|---|---|---|---|
| 자동매매 정지 상태 + REGIME type 미선택 | `자동매매 실행` 클릭 | 자동매매 실행을 차단하고 REGIME 미선택 자동매매 경고 팝업을 표시한다. | REGIME 미선택 경고 팝업 상태가 `open`이 된다. | `REGIME type을 먼저 선택해주세요` 팝업이 표시된다. |
| 자동매매 정지 상태 + REGIME type 선택됨 | `자동매매 실행` 클릭 | 선택된 REGIME type을 기준으로 자동매매 시작 확인 팝업을 표시한다. | 시작 확인 팝업 상태가 `open`이 된다. | `자동매매를 시작할까요?` 팝업이 표시된다. |
| 자동매매 실행 중 | `자동매매 실행 중` 상태 버튼 클릭 | 중복 시작을 수행하지 않는다. | 자동매매 상태 유지 | 버튼은 실행 중 상태 표시로 유지된다. |

자동매매 실행 버튼은 정지 상태에서만 시작 계열 팝업을 여는 동작을 수행한다. REGIME type이 선택되지 않은 경우에는 자동매매 시작 확인 팝업으로 진행하지 않고, 먼저 REGIME type 선택을 요구하는 경고 팝업을 표시한다. 이미 자동매매가 실행 중이면 동일 전략을 중복 실행하지 않는다.

| 현재 상태 | 사용자 이벤트 | 시스템 반응 | 상태 변경 | 시각적 피드백 |

REGIME 변경은 REGIME type 선택 확인 팝업에서 `실행`을 눌렀을 때 확정된다. `취소`를 누르면 현재 REGIME 상태를 변경하지 않는다. REGIME 변경은 이미 체결된 주문 기록을 변경하지 않는다. 자동매매 실행 중 REGIME을 바꾸는 경우, 변경 이후 발생하는 신규 판단과 신규 주문에 적용한다.

# 6. Entry & Exit Rule

Entry & Exit Rule은 화면이나 팝업에 진입하는 순간 자동으로 수행되어야 하는 규칙과, 화면이나 팝업을 벗어날 때 수행되어야 하는 규칙이다. 버튼 클릭 자체의 기능 설명이 아니라, 화면 생명주기 관점의 규칙이다.

---

## ER-01. 메인 화면 Entry Rule

| 항목 | 내용 |
|---|---|
| 진입 대상 | 메인 화면 |
| 진입 이벤트 | 프로그램 실행, 메인 화면 복귀, 자동매매 화면 재진입 |
| Entry Rule | 전략 이름을 표시한다. 실시간 연결 상태를 확인하고 `LIVE` 상태를 표시한다. 현재 추천된 REGIME type을 불러와 REGIME 판단 패널에 반영한다. 기본 또는 마지막 선택된 차트 주기를 기준으로 ETH 가격 차트를 렌더링한다. 마지막 선택된 트레이더 패널 탭 또는 기본 탭을 표시한다. 보유 자산, 현재 상태 수익률, 분할 매수 비율, 분할 매도 비율을 표시한다. |
| 기본 표시 상태 | 차트, REGIME 패널, 트레이더 패널, 거래/계좌 영역이 동시에 표시된다. |

메인 화면에 진입할 때 자동매매 상태가 실행 중이면 우측 상단에 `자동매매 실행 중` 상태가 표시되어야 하고, 정지 상태이면 `자동매매 실행`이 가능한 상태로 표시되어야 한다.

| Exit Rule | 현재 REGIME 선택값, 자동매매 실행 상태, 차트 주기, 보조지표 표시 상태, 트레이더 패널 탭 상태, 분할 매수/매도 설정값을 유지한다. |
| 유지되어야 하는 상태 | 자동매매 실행 여부, 보유 포지션, 주문 감시 상태, 사용자 설정값 |

메인 화면을 벗어난다고 해서 자동매매가 중지되어서는 안 된다. 자동매매 중지는 반드시 `매매 중지` 버튼과 확인 팝업을 통해서만 수행한다.

| `취소` 클릭 | CSV 파일을 생성하지 않고 팝업을 닫는다. 팝업 내부에서 변경한 임시 저장 위치와 날짜 범위는 실제 내보내기로 확정하지 않는다. |
| `내보내기` 성공 | 선택된 저장 위치, 날짜 범위, 파일명 기준으로 CSV 파일을 생성하고 팝업을 닫거나 성공 상태를 표시한다. |
| `내보내기` 실패 | 팝업을 유지하고 실패 원인을 표시한다. 저장 위치 누락, 날짜 범위 오류, 파일 생성 실패 등을 사용자에게 알려야 한다. |
| CSV 내보내기 팝업 외부 영역 클릭 | CSV 파일을 생성하지 않고 CSV 내보내기 팝업을 닫는다. 팝업 내부에서 변경한 임시 저장 위치와 날짜 범위는 실제 내보내기로 확정하지 않는다. |
| 달력 팝업만 닫힘 | CSV 내보내기 팝업은 유지하고 달력 팝업만 닫는다. 날짜 셀을 선택한 경우에는 선택된 날짜를 시작일 또는 종료일 입력값에 반영하고, 달력 영역 외부를 클릭한 경우에는 날짜 변경 없이 달력 팝업만 닫는다. |

CSV 내보내기 팝업을 닫는 행위와 CSV 파일을 실제로 생성하는 행위는 구분되어야 한다.

## ER-15. 달력 팝업 Entry Rule

| 항목 | 내용 |
|---|---|
| 진입 대상 | 날짜 선택 달력 팝업 |
| 진입 이벤트 | CSV 내보내기 팝업에서 시작일/종료일 입력 영역 또는 달력 아이콘 클릭 |
| Entry Rule | 클릭된 필드가 시작일인지 종료일인지 저장한다. 해당 필드의 현재 날짜를 기준으로 달력을 표시한다. 현재 선택된 날짜 셀을 강조 표시한다. |
| 기본 표시 상태 | 연도, 월, 이전/다음 이동 버튼, 요일, 날짜 셀 표시 |

시작일에서 열린 달력과 종료일에서 열린 달력은 UI 모양이 같아도 수정 대상이 다르므로, Entry 단계에서 반드시 날짜 선택 대상을 설정해야 한다.

## ER-16. 달력 팝업 Exit Rule

| 종료 방식 | Exit Rule |
|---|---|
| 날짜 셀 클릭 | 선택한 날짜를 현재 날짜 선택 대상에 반영하고 달력 팝업을 닫는다. CSV 내보내기 팝업은 유지한다. |
| 달력 영역 외부 클릭 | 날짜 변경 없이 달력 팝업만 닫는다. CSV 내보내기 팝업 전체는 닫지 않고 그대로 유지한다. |
| 월/연도 이동 후 닫힘 | 날짜를 선택하지 않았다면 시작일/종료일 값은 변경하지 않는다. |

달력 팝업을 닫아도 CSV 내보내기 팝업 전체가 닫혀서는 안 된다.

## ER-17. 차트 전체화면 모드 Entry & Exit Rule

| 구분 | 규칙 |
|---|---|
| Entry Rule | 전체화면 아이콘을 클릭하면 ETH 가격 차트를 확대 표시한다. 현재 차트 주기와 보조지표 표시 상태를 그대로 유지한다. |
| Exit Rule | 전체화면 종료 조작을 수행하면 기존 메인 화면 레이아웃으로 복귀한다. 차트 주기, 보조지표 설정, REGIME, 자동매매 상태는 유지한다. |

차트 전체화면 모드는 보기 방식만 변경한다. 거래 설정이나 자동매매 상태를 변경하지 않는다.

## ER-18. 차트 드로잉 모드 Entry & Exit Rule

| 구분 | 규칙 |
|---|---|

| Exit Rule | 드로잉 모드를 종료하면 일반 차트 조작 모드로 복귀한다. 작성된 드로잉 객체의 유지 여부는 별도 정책에 따른다. |

드로잉 모드에서 생성된 표시선이나 메모는 거래 판단 로직에 직접 사용하지 않는다. 해당 객체는 사용자의 시각적 분석 보조 자료로만 취급한다.

# 8. UI Rule 검증 체크리스트

| 체크 항목 | 검증 내용 |
|---|---|
| Constant Behaviour 분리 여부 | 상태와 무관하게 항상 같은 동작을 하는 UI 객체가 Constant Behaviour에 정의되어 있는가? |
| Varying Behaviour 분리 여부 | 같은 버튼이 상태에 따라 다른 결과를 내는 경우 조건별로 분기되어 있는가? |
| Entry Rule 정의 여부 | 각 화면과 팝업에 진입할 때 초기 표시값, 데이터 조회, 상태 반영 규칙이 정의되어 있는가? |
| Exit Rule 정의 여부 | 화면 또는 팝업을 닫을 때 유지해야 할 상태와 폐기해야 할 임시 상태가 구분되어 있는가? |
| 자동매매 상태 보존 | 화면 이동이나 팝업 닫힘만으로 자동매매가 중지되지 않는가? |
| 포지션 상태 분기 | 보유 포지션 유무에 따라 매매 중지 팝업이 다르게 표시되는가? |
| REGIME 미선택 실행 차단 | REGIME type이 선택되지 않은 상태에서 자동매매 실행을 시도하면 자동매매가 시작되지 않고 경고 팝업이 표시되는가? |
| REGIME 선택 위치 안내 | REGIME 미선택 경고 팝업에서 `REGIME 선택`을 누르면 REGIME 판단 패널 전체가 점멸 강조되는가? |
| REGIME 선택 확인 | REGIME type 버튼 클릭만으로 즉시 적용되지 않고, 확인 팝업에서 `실행`을 눌렀을 때만 적용되는가? |
| CSV 검증 | 저장 위치, 날짜 범위, 파일 생성 성공/실패가 분기 처리되는가? |
| 단일 선택 그룹 | REGIME, 차트 주기, 탭, 필터, 기간 프리셋에서 하나만 선택되는가? |
| 팝업 우선순위 | 확인성 팝업이 열려 있을 때 배경 화면 조작이 제한되는가? |
| 상태 초기화 방지 | 화면 이동, 차트 주기 변경, 탭 전환으로 REGIME, 자동매매 상태, 주문 비율이 초기화되지 않는가? |
