# UI Behavior 명세서

## 1. 문서 목적

본 문서는 제공된 UI 화면을 기준으로, 화면에 존재하는 각 버튼과 인터랙션 컨트롤의 역할을 정의한다. 버튼 동작은 사용자가 화면에서 클릭했을 때 시스템이 수행해야 하는 UI 반응, 상태 변경, 데이터 갱신, 팝업 표시, 화면 이동을 중심으로 작성한다.

## 2. 공통 UI Behavior

| 버튼/컨트롤 | 위치 | 역할 |
|---|---|---|
| `매매 중지` | 상단 우측, 빨간색 버튼 | 자동매매가 실행 중일 때 매매 중지 확인 팝업을 연다. 현재 보유 포지션이 없으면 `매매를 중지할까요?` 팝업을 표시하고, 보유 포지션이 있으면 `보유 포지션이 있습니다` 팝업을 표시한다. |
| `자동매매 실행` | 상단 우측, 초록색 버튼 | 자동매매가 정지 상태일 때 자동매매 시작 확인 팝업을 연다. 팝업에서는 현재 선택된 REGIME type을 기준으로 거래를 시작할지 확인한다. |
| `자동매매 실행 중` | 상단 우측, 초록색 상태 버튼 | 자동매매가 이미 실행 중임을 표시한다. 실행 중 상태에서는 중복 시작을 방지하기 위해 새 시작 동작을 수행하지 않는다. |
| `LIVE` | 상단 상태 표시 | 실시간 REST API 및 Websocket 데이터 연결 상태를 나타내는 표시 요소이다. 버튼 동작은 없다. |

| `type1 약상승` | type1을 변경 후보로 선택하고 확인 팝업을 표시한다. 실행·정지 모두 `실행` 확인 후 backend 적용이 성공하면 현재 적용 REGIME을 확정한다. 취소·실패 시 기존 적용값을 유지한다. |
| `type2 강상승` | type2을 변경 후보로 선택하고 확인 팝업을 표시한다. 실행·정지 모두 `실행` 확인 후 backend 적용이 성공하면 현재 적용 REGIME을 확정한다. 취소·실패 시 기존 적용값을 유지한다. |
| `type3 약하락` | type3을 변경 후보로 선택하고 확인 팝업을 표시한다. 실행·정지 모두 `실행` 확인 후 backend 적용이 성공하면 현재 적용 REGIME을 확정한다. 취소·실패 시 기존 적용값을 유지한다. |
| `type4 강하락` | type4을 변경 후보로 선택하고 확인 팝업을 표시한다. 실행·정지 모두 `실행` 확인 후 backend 적용이 성공하면 현재 적용 REGIME을 확정한다. 취소·실패 시 기존 적용값을 유지한다. |

## 4. 메인 화면 - ETH 가격 차트 영역

| 버튼/컨트롤 | 역할 |
|---|---|
| `1분` | 차트 캔들 주기를 1분봉으로 변경한다. 클릭 시 1분봉 데이터로 차트를 다시 렌더링하고, 선택된 보조지표도 같은 주기에 맞춰 갱신한다. |
| `30분` | 차트 캔들 주기를 30분봉으로 변경한다. 클릭 시 30분봉 데이터로 차트를 다시 렌더링한다. |
| `4시간` | 차트 캔들 주기를 4시간봉으로 변경한다. 클릭 시 4시간봉 데이터로 차트를 다시 렌더링한다. |
| `1일` | 차트 캔들 주기를 일봉으로 변경한다. 클릭 시 1일봉 데이터로 차트를 다시 렌더링한다. |
| `지표 설정` | 차트 보조지표 설정 팝업을 연다. 팝업에서는 EMA9, 볼린저밴드, 거래량 표시 여부를 설정한다. |
| 차트 드로잉 아이콘 | 차트 하단 우측의 펜/드로잉 형태 아이콘이다. 클릭 시 차트 위에 사용자가 추세선, 표시선, 메모성 표시 등을 추가할 수 있는 드로잉 모드로 진입한다. |
| 전체화면 아이콘 | 차트 하단 우측의 확장 아이콘이다. 클릭 시 ETH 가격 차트를 전체화면 또는 확대 보기 모드로 전환한다. |

## 5. 메인 화면 - 지표 설정 팝업

| 버튼/컨트롤 | 역할 |
|---|---|
| `EMA9` 토글 | 차트에 EMA9 지수 이동 평균선을 표시하거나 숨긴다. ON이면 차트에 EMA9 선을 표시하고, OFF이면 차트에서 제거한다. |
| `볼린저밴드` 토글 | 차트에 볼린저밴드 상단/하단 밴드를 표시하거나 숨긴다. ON이면 상단/하단 밴드를 표시하고, OFF이면 차트에서 제거한다. |
| `거래량(Volume)` 토글 | 차트 하단에 거래량 막대를 표시하거나 숨긴다. ON이면 거래량 영역을 표시하고, OFF이면 숨긴다. |

## 6. 메인 화면 - 트레이더 패널

| 버튼/컨트롤 | 역할 |
|---|---|
| `체결 내역` 탭 | 트레이더 패널을 최근 체결 목록 보기로 전환한다. 최근 매수/매도 체결 내역, 체결 시간, 체결 가격, 수량, 수익률 정보를 표시한다. |
| `실시간 지표` 탭 | 트레이더 패널을 실시간 지표 보기로 전환한다.
| `전체 보기` | 최근 체결 목록의 전체 상세 화면으로 이동한다. 클릭 시 `거래 내역 상세` 화면을 연다. |

## 7. 메인 화면 - 거래 / 계좌 영역

| 버튼/컨트롤 | 역할 |
|---|---|
| 분할 매수 `-` 버튼 | 분할 매수 비율을 한 단계(10%) 감소시킨다. 감소 후 현재 비율 배지가 갱신된다. |
| 분할 매수 슬라이더 | 사용자가 드래그하여 분할 매수 비율을 직접 조정한다. 조정된 값은 다음 매수 주문의 주문 금액 산정에 사용된다. |
| 분할 매수 `+` 버튼 | 분할 매수 비율을 한 단계(10%) 증가시킨다. 증가 후 현재 비율 배지가 갱신된다. |
| 분할 매도 `-` 버튼 | 분할 매도 비율을 한 단계(10%) 감소시킨다. 감소 후 현재 비율 배지가 갱신된다. |
| 분할 매도 슬라이더 | 사용자가 드래그하여 분할 매도 비율을 직접 조정한다. 조정된 값은 다음 매도 주문의 주문 수량 산정에 사용된다. |
| 분할 매도 `+` 버튼 | 분할 매도 비율을 한 단계(10%) 증가시킨다. 증가 후 현재 비율 배지가 갱신된다. |

## 8. 자동매매 시작 확인 팝업

팝업 제목: `자동매매를 시작할까요?`

| 버튼/컨트롤 | 역할 |
|---|---|
| `취소` | 자동매매 시작을 취소하고 팝업을 닫는다. REGIME 선택값은 변경하지 않는다. |
| `거래 시작` | 현재 선택된 거래 타입을 기준으로 자동매매를 시작한다. 실시간 주문 감시를 시작하고, 상단 상태를 자동매매 실행 중 상태로 변경한 뒤 팝업을 닫는다. |

## 9. 자동매매 중지 확인 팝업 - 보유 포지션 없음

팝업 제목: `매매를 중지할까요?`

| 버튼/컨트롤 | 역할 |
|---|---|
| `취소` | 매매 중지를 취소하고 팝업을 닫는다. 자동매매는 계속 실행된다. |
| `매매 중지` | 현재 보유 중인 포지션이 없을 때 자동매매 감시와 신규 주문 생성을 중지한다. 중지 성공 시 자동매매 상태를 정지 상태로 변경하고 팝업을 닫는다. |

## 10. 자동매매 중지 확인 팝업 - 보유 포지션 있음

팝업 제목: `보유 포지션이 있습니다`

| 버튼/컨트롤 | 역할 |
|---|---|
| `취소` | 강제 매도 및 매매 중지를 실행하지 않고 팝업을 닫는다. 자동매매는 계속 실행된다. |
| `강제 매도 후 중지` | 현재 보유 중인 ETH 포지션을 강제 매도한 뒤 자동매매를 중지한다. 매도 주문 처리 후 자동매매 감시와 신규 주문 생성을 중지한다. |

## 11. 거래 내역 상세 화면

| 버튼/컨트롤 | 역할 |
|---|---|
| `돌아가기` | 이전 화면인 메인 화면으로 이동한다. 메인 화면의 REGIME 상태, 차트 주기, 자동매매 상태는 유지한다. |
| `오늘` | 거래 내역 필터를 오늘 날짜 기준으로 적용한다. 오늘 발생한 체결 내역만 테이블에 표시한다. |
| `전체` | 거래 구분 필터를 전체로 변경한다. 매수와 매도 체결 내역을 모두 표시한다. |
| `매수` | 거래 구분 필터를 매수로 변경한다. 매수 체결 내역만 테이블에 표시한다. |
| `매도` | 거래 구분 필터를 매도로 변경한다. 매도 체결 내역만 테이블에 표시한다. |
| `CSV 내보내기` | 거래 내역을 CSV 파일로 저장하기 위한 `CSV 내보내기` 팝업을 연다. |

## 12. CSV 내보내기 팝업

팝업 제목: `CSV 내보내기`

| 버튼/컨트롤 | 역할 |
|---|---|
| `위치 선택` | CSV 파일을 저장할 폴더를 선택하는 파일 시스템 폴더 선택 창을 연다. 선택 완료 시 `선택된 폴더` 경로를 갱신한다. |
| `오늘` | 내보낼 기간을 오늘 하루로 설정한다. 시작일과 종료일을 오늘 날짜로 자동 설정한다. 기간 변경만으로 파일명을 바꾸지 않는다. |
| `최근 7일` | 내보낼 기간을 최근 7일로 설정한다. 시작일은 오늘 기준 6일 전, 종료일은 오늘로 설정한다. |
| `최근 30일` | 내보낼 기간을 최근 30일로 설정한다. 시작일은 오늘 기준 29일 전, 종료일은 오늘로 설정한다. |
| `날짜 선택` | 사용자가 시작일과 종료일을 직접 선택하는 수동 기간 선택 모드로 전환한다. |
| `시작일 선택` 입력 영역 | 시작일을 선택하기 위한 날짜 선택 필드이다. 클릭 시 시작일 달력 팝업을 연다. |
| `시작일 선택` 달력 아이콘 | 시작일 달력 팝업을 연다. 입력 영역 클릭과 동일하게 동작한다. |
| `종료일 선택` 입력 영역 | 종료일을 선택하기 위한 날짜 선택 필드이다. 클릭 시 종료일 달력 팝업을 연다. |
| `종료일 선택` 달력 아이콘 | 종료일 달력 팝업을 연다. 입력 영역 클릭과 동일하게 동작한다. |
| `취소` | CSV 내보내기를 취소하고 팝업을 닫는다. 저장 위치, 날짜 범위, 파일명 변경은 실제 파일 생성으로 이어지지 않는다. |
| `내보내기` | 선택된 저장 위치, 날짜 범위, 파일명을 기준으로 거래 내역 CSV 파일을 생성한다. 내보내기 성공 후 팝업을 닫거나 성공 상태를 표시한다. |

## 13. CSV 내보내기 - 달력 팝업

| 버튼/컨트롤 | 역할 |
|---|---|
| 이전 달 `‹` 버튼 | 현재 표시 중인 달력의 월을 한 달 이전으로 이동한다. |
| 다음 달 `›` 버튼 | 현재 표시 중인 달력의 월을 한 달 다음으로 이동한다. |
| `2026년` 연도 선택 버튼 | 달력의 연도를 선택하거나 변경하는 드롭다운을 연다. 선택된 연도에 맞춰 달력 날짜를 다시 표시한다. |
| `5월`, `6월` 월 선택 버튼 | 달력의 월을 선택하거나 변경하는 드롭다운을 연다. 선택된 월에 맞춰 달력 날짜를 다시 표시한다. |
| 날짜 셀 `1`~`31` | 해당 날짜를 시작일 또는 종료일로 선택한다. 시작일 달력에서 선택하면 시작일 필드가 갱신되고, 종료일 달력에서 선택하면 종료일 필드가 갱신된다. |

## 14. 화면 이동 요약

| 사용자 동작 | 결과 |
|---|---|
| 메인 화면에서 `전체 보기` 클릭 | `거래 내역 상세` 화면으로 이동한다. |

| CSV 내보내기 팝업에서 날짜 입력 영역 클릭 | 시작일 또는 종료일 달력 팝업을 표시한다. |
