# 외부 수동 매도 후 재시작 실패 수정

2026-09-20. 이전 외부 매도 복구 기능이 실행됐지만, 현재 포지션보다 큰 매도를 모두 거부하여
이전 잔여 ETH가 함께 매도된 이번 경우를 처리하지 못했다.

## 확인한 원인

22:01과 22:02 시작 로그는 `build_external_exit_trades()`의 수량 검사에서 실패했다.
22:02:06 로그의 `ValueError` 위치는 수정 전 `external_exit_recovery.py:46`이며,
격리 재현에서도 같은 위치에서 `external exit quantity or base commission is ambiguous`가 발생했다.

공식 읽기 전용 조회에서 매도 주문 `49962570529`, 체결 `4371071673`,
체결가 `2580.85 USDT`, 수수료 `0.00954915 USDT`, 미체결 주문·주문 목록 없음이 확인됐다.
기존 잔여는 9월 11일 자동 예치되고 9월 15일 보상과 함께 상환되어 매도 시점에 현물에 있었다.

9월 10일 수정은 단일 포지션에서 외부 매도 후 소액 잔량이 생기는 경우를 지원했다.
이번은 다음 포지션과 이전 잔여를 함께 매도한 경우다. 또 Earn 대조는 종전에는 외부 매도 후보 검증
뒤에 실행되어, 앞 단계의 보상 미반영 수량 검사에 도달하면 실패할 수 있었다.

## 수정 내용

- 요청량을 현재 포지션과 검증된 잔여 원금의 합으로 제한하고, 실제 체결의 초과분만 잔여에서 소비한다.
- 현재 포지션의 원가와 소비한 잔여의 평균 원가를 합산해 실제 SELL의 손익을 계산한다.
- 기존 이관 장부와 과거 Trade는 그대로 보존한다. 소비는 새 SELL의 이력 순번에서 재생하므로
  별도 파일 저장이 실패해 이중 차감되거나 복구가 누락되는 구간을 만들지 않는다.
- 외부 매도 후보 검증에 Earn 보관·보상을 포함하고, 주문·잔고·Earn 근거를 재조회하여 변경을 차단한다.
  매도 당시 Earn에 묶여 있던 잔여, 미확인 추가 잔고, 입출금, 초과 주문량, ETH 매도 수수료는 계속 거부한다.
- 다음 매수 포지션의 복원·시작 조건 및 종료 시 이력 검증도 같은 잔여 소비 회계를 사용한다.
- 전체 검사에서 발견한 기존 `average_fill_price` 설명 누락은 주석 형식만 보완했다.

실제 이력 복사본의 복구 결과는 SELL 한 건 추가, 포지션 0, 잔여 원금 0.00009230 ETH다.
매도 배분 원가는 `9.711229 USDT`, 실현손익은 `-0.17163315 USDT`이며,
남은 잔여 취득원가는 `0.2258107027027027027027027027027030 USDT`다.

최종 검사의 Phase 13 GAP 문구와 진단 로그 실패 문구는 해당 테스트가 의도적으로 생성한 출력이다.
검증 중 실제 주문 제출·취소·이체·예치·상환이나 자동매매 시작은 수행하지 않았다.
